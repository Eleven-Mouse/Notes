## 六、面试答题模板

### 五步答题法

```
第1步：是什么（定义/概念，10 秒）
  "XXX 是 ..."

第2步：为什么（解决什么问题/背景，30 秒）
  "它的出现是为了解决 ..."

第3步：怎么实现（原理/源码/流程，1-2 分钟）
  "它的核心原理是 ...，具体来说 ..."

第4步：有什么问题（局限性/trade-off，30 秒）
  "但它也存在 ... 的问题"

第5步：生产怎么用（实战经验/最佳实践，30 秒）
  "在实际项目中，我们通常会 ..."
```

### 答题示例：HashMap

```
是什么：HashMap 是基于哈希表实现的 Key-Value 存储结构
为什么：解决快速查找的问题，期望 O(1) 时间复杂度
怎么实现：数组 + 链表/红黑树，通过 hash 定位数组下标，
         JDK1.8 链表长度 >= 8 且数组长度 >= 64 转红黑树
有什么问题：线程不安全（put 可能死循环/数据覆盖），
           扩容时性能抖动
生产怎么用：多线程用 ConcurrentHashMap，
           初始化指定容量避免频繁扩容
```

### 项目描述写法

```text
项目名称：XXX 电商秒杀系统
技术栈：Spring Cloud Alibaba + Nacos + Sentinel + Seata + Redis + Kafka + MySQL

项目描述：
  基于微服务架构的电商秒杀平台，支持万级 QPS 的秒杀抢购

核心工作（用数据说话）：
  1. 基于 Redis + Lua 实现原子库存扣减，QPS 从 500 提升到 10000+
  2. 引入 Sentinel 限流 + Kafka 异步下单，系统吞吐量提升 80%
  3. 使用 Seata AT 模式解决分布式事务，订单-库存-支付数据一致性 100%
  4. MySQL 分库分表 + 读写分离，支撑百万级订单数据查询 < 50ms
  5. Redis 集群 + 本地缓存二级架构，缓存命中率 99.5%
```
