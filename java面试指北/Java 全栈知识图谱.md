# Java 全栈知识图谱 — 全局骨架

  

> 面向 2026 互联网大厂 Java 后端招聘标准

> 定位：系统学习 / 面试准备 / 项目查漏补缺 / 架构理解

## 一、完整知识图谱（树状结构）

  

```

Java 全栈技术体系

│

├── 1. Java 基础 ⭐⭐⭐ 🔥🔥🔥（一切的地基）

│   ├── 数据类型与语法

│   ├── 面向对象（封装 / 继承 / 多态）

│   ├── 泛型与类型系统

│   ├── 反射机制

│   ├── 注解

│   └── 异常体系

│

├── 2. JVM ⭐⭐⭐ 🔥🔥🔥（理解底层运转引擎）

│   ├── 内存结构（堆 / 栈 / 方法区 / 元空间）

│   ├── 类加载机制（双亲委派）

│   ├── 垃圾回收（GC 算法 / 收集器）

│   └── 调优与监控

│

├── 3. 并发编程 ⭐⭐⭐ 🔥🔥🔥（大厂核心考察点）

│   ├── 线程基础（Thread / Runnable / Callable）

│   ├── 线程池（ThreadPoolExecutor）

│   ├── volatile / synchronized / CAS

│   ├── AQS 与 Lock

│   ├── 并发容器（ConcurrentHashMap / BlockingQueue）

│   └── ThreadLocal

│

├── 4. 锁机制 ⭐⭐⭐ 🔥🔥🔥（从并发中独立拆出，面试重点）

│   ├── synchronized 锁升级（偏向 → 轻量 → 重量）

│   ├── 乐观锁 vs 悲观锁

│   ├── 公平锁 / 非公平锁

│   ├── 可重入锁 / 读写锁

│   └── 分布式锁

│

├── 5. 集合框架 ⭐⭐⭐ 🔥🔥🔥（日常开发最高频）

│   ├── List（ArrayList / LinkedList）

│   ├── Map（HashMap / TreeMap / ConcurrentHashMap）

│   ├── Set（HashSet / TreeSet）

│   └── Queue（ArrayDeque / PriorityQueue / BlockingQueue）

│

├── 6. IO / NIO ⭐⭐ 🔥🔥（理解网络编程基础）

│   ├── BIO / NIO / AIO 模型

│   ├── ByteBuffer / Channel / Selector

│   └── Netty 基础（了解）

│

├── 7. 网络编程 ⭐⭐ 🔥🔥（支撑分布式通信理解）

│   ├── TCP/IP 三次握手 / 四次挥手

│   ├── HTTP / HTTPS

│   └── Socket 编程基础

│

├── 8. Spring 全家桶 ⭐⭐⭐ 🔥🔥🔥（企业开发核心框架）

│   ├── Spring（IOC / AOP / 事务）

│   ├── Spring MVC（请求流转）

│   ├── Spring Boot（自动装配 / Starter）

│   └── Spring Cloud（了解级）

│

├── 9. MyBatis ⭐⭐ 🔥🔥（ORM 框架）

│   ├── 执行流程

│   ├── 动态 SQL

│   └── 一级 / 二级缓存

│

├── 10. MySQL ⭐⭐⭐ 🔥🔥🔥（后端必考数据库）

│   ├── 索引（B+树 / 聚簇 / 非聚簇）

│   ├── 事务与隔离级别

│   ├── 锁机制（行锁 / 表锁 / MVCC）

│   └── SQL 调优（执行计划 / 慢查询）

│

├── 11. Redis ⭐⭐⭐ 🔥🔥🔥（缓存必考）

│   ├── 五大数据结构

│   ├── 持久化（RDB / AOF）

│   ├── 缓存问题（穿透 / 击穿 / 雪崩）

│   └── 分布式锁

│

├── 12. 消息队列（MQ）⭐⭐ 🔥🔥（解耦 / 削峰）

│   ├── 消息模型

│   ├── 消息可靠性

│   ├── 重复消费 / 顺序消费

│   └── Kafka 或 RabbitMQ（选一个深入）

│

├── 13. 微服务 ⭐ 🔥（了解级，架构认知）

│   ├── 服务注册发现

│   ├── 配置中心

│   ├── 网关

│   └── 负载均衡

│

├── 14. 分布式基础 ⭐⭐ 🔥🔥（架构思维）

│   ├── CAP / BASE 理论

│   ├── 分布式 ID

│   ├── 分布式事务

│   └── 一致性哈希

│

└── 15. 系统设计基础 ⭐ 🔥（综合能力体现）

    ├── 高并发设计模式

    ├── 限流 / 降级 / 熔断

    └── 秒杀系统设计思路

```

## 三、模块核心作用与关系

  
| 模块 | 核心作用 | 被谁依赖 | 依赖谁 |
|------|---------|---------|--------|
| Java 基础 | 语言根基，一切上层建筑的前提 | 所有模块 | 无 |
| JVM | 理解程序运行底座，排查线上问题 | 并发/集合/IO | Java 基础 |
| 并发编程 | 高并发场景下的线程安全与性能优化 | Spring/分布式/系统设计 | JVM/集合/锁 |
| 锁机制 | 并发控制的底层实现 | 并发编程/MySQL/Redis | JVM/Java 基础 |
| 集合框架 | 数据在内存中的组织方式 | 并发容器/Spring/MyBatis | Java 基础 |
| IO/NIO | 理解网络通信与文件操作模型 | 网络编程/MQ/Netty | Java 基础 |
| 网络编程 | 理解分布式通信基础 | MQ/微服务/系统设计 | IO/NIO |
| Spring | 企业级开发框架，简化开发 | MyBatis/MySQL/Redis/MQ | Java 基础/并发 |
| MyBatis | 数据库访问层 ORM | Spring | Java 基础/MySQL |
| MySQL | 关系型数据持久化存储 | MyBatis/Spring/系统设计 | 锁/事务 |
| Redis | 高性能缓存，减轻 DB 压力 | Spring/分布式/系统设计 | 数据结构/网络 |
| MQ | 异步解耦、削峰填谷 | 微服务/系统设计 | 网络编程/IO |
| 微服务 | 大型系统架构拆分方案 | 系统设计 | Spring/网络/分布式 |
| 分布式 | 理解多节点协作的理论基础 | 微服务/系统设计 | 网络/并发/MySQL |
| 系统设计 | 综合运用所有知识的场景题 | — | 所有模块 |

## 四、学习路径建议

  

```

Phase 1（地基，2-3 周）:  Java 基础 → 集合框架 → JVM

Phase 2（核心，3-4 周）:  并发编程 → 锁机制 → IO/NIO

Phase 3（框架，2-3 周）:  Spring → Spring MVC → Spring Boot → MyBatis

Phase 4（存储，2-3 周）:  MySQL → Redis

Phase 5（进阶，2-3 周）:  MQ → 微服务 → 分布式 → 系统设计

```
