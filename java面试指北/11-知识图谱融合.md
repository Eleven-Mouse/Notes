## 二、完整调用链（一个请求的旅程）

  

### 场景：用户下单

  

```

用户点击"下单"

    │

    ▼

【1. 客户端】

    发送 HTTP POST /api/order

    │

    ▼

【2. 网关层】Spring Cloud Gateway

    ├── 路由匹配（Path=/api/order/**）

    ├── 鉴权（Token 校验 → Redis 查 Session）

    ├── 限流（Sentinel 令牌桶）

    └── 负载均衡（选择订单服务实例）

    │

    ▼

【3. Controller 层】Spring MVC

    ├── DispatcherServlet 接收请求

    ├── HandlerMapping 找到 OrderController.createOrder()

    ├── 参数校验（@Valid）

    └── 返回统一响应

    │

    ▼

【4. Service 层】Spring

    ├── @Transactional 开启事务（MySQL InnoDB）

    ├── 业务逻辑

    │   ├── 查商品信息（Redis 缓存 → 未命中查 MySQL → 回填 Redis）

    │   ├── 扣库存（乐观锁 version / Redis Lua 脚本）

    │   ├── 扣余额（调用支付服务 → OpenFeign HTTP/RPC）

    │   └── 创建订单（MyBatis → MySQL INSERT）

    ├── 事务提交 / 回滚

    └── 发布领域事件（Kafka Producer 发送消息）

    │

    ▼

【5. 消息消费】Kafka

    ├── 积分服务消费 → 加积分

    ├── 通知服务消费 → 发短信/邮件

    ├── 物流服务消费 → 创建运单

    └── 数据同步服务消费 → 同步到 ES（搜索用）

    │

    ▼

【6. 数据流转】

    MySQL（订单/商品/用户数据）

    Redis（缓存 / 分布式锁 / Session）

    Elasticsearch（商品搜索）

    Kafka（异步消息）

    │

    ▼

【7. 返回响应】

    Gateway → 客户端

    {"code": 200, "data": {"orderId": "20260426001"}}

```

### 面试答题模板

  

```

每个知识点按以下结构回答：

  

1. 是什么（一句话定义）

2. 为什么需要（解决什么问题）

3. 怎么实现（核心原理）

4. 有什么问题/局限

5. 生产中怎么用（实战经验）

  

示例（HashMap）：

  HashMap 是基于数组+链表+红黑树实现的 KV 存储

  用于快速查找（O(1) 平均时间复杂度）

  通过 hash 定位桶 → 链表/红黑树解决冲突 → JDK8 链表长度>=8 转红黑树

  问题：非线程安全 → 多线程用 ConcurrentHashMap

  生产：初始化指定容量（避免扩容）→ key 用 String/Integer（不可变）

```

## 四、项目补强建议

  

### 实习/校招项目推荐

  

```

推荐项目类型（按含金量排序）：

  

1. 秒杀系统（综合性最强）

   技术栈：Spring Boot + Redis + Kafka + MySQL

   涵盖：高并发 / 分布式锁 / 缓存 / MQ / 限流

  

2. 短链系统（设计题热门）

   技术栈：Spring Boot + MySQL + Redis + 布隆过滤器

   涵盖：分布式 ID / 缓存 / 数据库设计

  

3. 社区/论坛系统（完整业务链）

   技术栈：Spring Boot + MyBatis-Plus + Redis + MySQL + ES

   涵盖：CRUD / 缓存 / 搜索 / 权限

  

4. RPC 框架（理解底层原理）

   技术栈：Netty + 自定义协议 + 动态代理 + ZooKeeper

   涵盖：网络编程 / 序列化 / 反射 / 服务治理

```

  

### 项目中如何体现技术深度

  

```

在简历和面试中这样描述项目：

  

低级写法（不要这样）：

  "使用 Redis 做缓存"

  

高级写法（要这样）：

  "使用 Redis 缓存热点数据，设置随机过期时间防止雪崩，

   用布隆过滤器解决缓存穿透，通过 Redisson 分布式锁保证

   库存扣减的原子性，QPS 从 500 提升到 5000"

  

每个技术点都要说清：

  1. 为什么用（解决了什么问题）

  2. 怎么用的（具体实现）

  3. 效果如何（量化指标）

```
