# 你好这里是 kunxing 的学习笔记

## 前言

**这个网站诞生的原因其实很朴素：我发现自己总是“学的时候热血沸腾，过两天记忆清空”。**  
**所以我决定把零散的思考和实践记下来，一方面督促自己持续总结，另一方面也给未来的自己留点“复活甲”。**  

 **这里的内容不一定完美，但都是真实踩坑后写下的心得。**  
 
**如果这些笔记刚好也帮你少走一点弯路、少掉几根头发，那就真的再好不过了。**  

**总之，把这里当作一个持续更新的学习现场：**  
**我认真记录，你随意逛逛；要是能一起进步，那就是这个网站最开心的彩蛋。**
